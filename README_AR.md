# جدولي التونسي

واجهة عربية RTL لمولّد الجداول المدرسية، مبنية لتكون مناسبة للمدارس التونسية.

## النسخة الحالية
- واجهة عربية كاملة.
- تعريف الأساتذة والساعات الأسبوعية.
- تعريف الأقسام والقاعات.
- تعريف الحصص.
- مدة الحصة ثابتة ولا تُجزّأ.
- دعم حصص الأفواج.
- منع تضارب الأستاذ والقسم والقاعة.
- توليد جدول أسبوعي من الاثنين إلى الجمعة، 08:00–14:00.
- حفظ البيانات محليًا.
- تصدير CSV وطباعة الجدول.

## التطوير القادم
سيتم توسيع المحرك ليشمل قيود FET المتقدمة: التوزيع اليومي للحصص، الفترات الممنوعة، القيود الإلزامية والتفضيلية، وربط أكثر دقة بين الأفواج والموارد.
